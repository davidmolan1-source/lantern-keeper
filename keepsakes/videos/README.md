# Keepsake videos

One folder per lesson. Drop family video files (`.mp4`) into the matching folder.

Multiple videos per lesson → game picks one at random (so different family members can record the same lesson and Arianna gets variety).

Filenames are free-form — pick anything (e.g. `granny.mp4`, `daddy.mp4`, `2026-recording.mp4`).

Prompts for each lesson are in `/Users/davidmolan/Documents/Nova Code/KEEPSAKE_PROMPTS.md`.
